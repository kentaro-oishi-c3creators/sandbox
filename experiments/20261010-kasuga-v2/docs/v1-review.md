# V1レビューとV2以降の方針

記録日: 2026-10-10 日本時間。ユーザーのレビューを受けた変更方針。

## V1の評価

V1はThree.jsで動く箱庭として成立した。女神の数・速度・停止、視点操作、PC・スマホ幅の表示を確認できた。見た目はかわいく整い、女神は小さな人の群れに近い。シュールさを追求するには、背景を日常の現実に近づける必要がある。

ユーザーの狙いは「かわいい奈良」より「マジの奈良」。実在する春日大社の参道を作り込み、普通の奈良が成立したところへ異物を入れる。女神の面白さをAIだけで断定しない。

## 合意した順番

1. **V2 / 現在の作業**: 自由の女神を外す。道路側の入口から、春日大社の参道を経て南門に到達する体験を作る。二之鳥居〜南門の短い区間を中心に、森・石灯籠・地面・石段・建築の見え方を作り込む。
2. **次の段階**: 少数の鹿を配置し、歩かせる。背景の空気を作る程度に留める。
3. **その次**: 少数の人を歩かせる。混雑の再現ではなく、日常のスケールの基準にする。
4. **最後**: 自由の女神を実寸比で歩かせる。まず1体。人の目線から巨大さを確認してから数を増やす。

鹿・人・女神はV2に追加しない。手水所の鹿を含む動物の造形も後の段階へ回す。

## 自由の女神の尺度

[米国国立公園局の寸法資料](https://home.nps.gov/stli/learn/historyculture/statue-statistics.htm)による像本体の高さは46.05m。[同局FAQ](https://home.nps.gov/stli/faqs.htm)では台座を含む全高は約93m。200mではない。

今後は「像本体46.05m」を暫定仕様とし、人の目線1.65m、人体約1.7mに対して実寸比を保つ。台座ごと歩かせるかは実装前に確認する。像の高さは足元から松明先端までであり、人の頭頂までの身長との比率とは区別する。

## V1を保存する構成

V1は `experiments/20261010-nara-liberty/` のまま維持する。今回の依頼ではV1のアプリやファイルを移動・変更しない。

V2は `experiments/20261010-kasuga-v2/` に独立させ、依存・起動・テスト・文書を持たせる。Vercelも専用プロジェクト・別URLにし、V1のデプロイを上書きしない。実験一覧を比較の入口にする。

## V2の判断基準

二之鳥居、深い木立、苔むした石灯籠、石段、朱色の南門・回廊から春日大社を感じられるか。1.65mの目線で歩くと建物の大きさが自然か。V1より現実に寄ったか。

公式資料に基づく順序と形の特徴を採用するが、実測の道路長・緯度経度・建築図面は未取得。手作業の再構成と測量済み再現を区別して評価する。
