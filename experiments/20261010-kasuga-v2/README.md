# 春日の杜を歩く — Nara V2

目的：シュールな企画の背景となる「普通の奈良」を先に作る。道路側の入口から森の参道を歩き、春日大社の南門へ到着するThree.jsの試作。
状態：完了（ステップ1の初回実装）。写実性の評価・写真照合は継続課題。

V1は隣の `20261010-nara-liberty/` に保存。V2は鹿・人・自由の女神を置かず、地面、木立、石灯籠、鳥居、石段、南門と回廊に集中する。現地資料を参考にした再構成で、実測モデルではない。

## 動かし方

Node.js 22.12以上（公開ビルドは24.x）、npm、WebGL2対応ブラウザが必要。WebGLはブラウザで3Dを描く仕組み。

```sh
cd experiments/20261010-kasuga-v2
npm ci
npm run dev -- --host 0.0.0.0
```

表示されたURLへアクセス。停止はCtrl+C。公開用のビルド（配信ファイル生成）と確認：

```sh
npm run build
npm run preview -- --host 0.0.0.0 --port 4174
# 別ターミナルで
npm run test:browser
```

Chromiumの標準パスは `/usr/bin/chromium`。別のパスは `CHROMIUM_PATH`、確認先は `BASE_URL` で指定できる。アプリ本体に秘密キー・環境変数は不要。テスト画像と結果は `test-results/` に生成しGitへ入れない。部品の実際のバージョンはロックファイルで固定する。

## 操作

- 「散策を始める」で参道を進む。停止・再開、速度変更、進行スライダー、4地点への移動ができる。
- 画面をドラッグして見回す。W/↑で前進、S/↓で後退、A/Dで左右を見る。スマホには前後ボタンを表示。
- 「俯瞰」で上から眺め、「散策視点」で戻る。リセットで入口へ戻る。
- 標準画質を初期値とする。「高精細」は端末によって重くなる。
