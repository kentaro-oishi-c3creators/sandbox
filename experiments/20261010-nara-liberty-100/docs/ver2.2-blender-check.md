# Blender制作経路の確認

確認日: 2026-10-11 日本時間。

このクラウド環境には `/usr/bin/blender`、Blender 4.3.2がある。ユーザーのPCに接続せず、`blender --background --python ...` で模型生成とGLB出力を実行できる。

1mの立方体を生成し、メートル単位・倍率1、底面を地面に置いて `.blend` と `.glb` を保存。Three.js 0.180.0のGLTFLoaderで読み込み、Box3（模型の外形を測る機能）で以下を確認した。

| 項目 | 結果 |
| --- | --- |
| Blender起動・Python模型生成 | 成功 |
| .blend保存 | 成功 |
| 非圧縮GLB出力 | 成功 |
| Three.js読込 | 成功 |
| 読込後の寸法 | X/Y/Zすべて1m |
| 上下方向と接地 | Yが上、底Y=0、頂Y=1 |

試験生成物は `/workspace/scratch/sandbox/blender-check/` に置き、東大寺の実装モデルとして扱わない。ブラウザ上でのGLB描画は未検証。今回の試験は模型生成・出力・読込・寸法まで。

Draco（3Dデータを圧縮する機能）のライブラリがないというログは出たが、非圧縮GLBの出力と読込は成功。初回は非圧縮で進め、必要時に圧縮対応を別途検証する。

制作時は建物ごとにメートル単位と原点を統一し、Blenderで形を作り、位置は出典付きの配置データで管理する。完成した模型の大きさを画面の印象だけで調整しない。元の `.blend` と生成手順を保持し、配信には `.glb` を用いる。
