# Ver2.2 対象範囲の参照資料

作成日: 2026-10-11 日本時間。

[取込計画](../../../docs/ver2.2-plan.md)と[テスト計画書](../../../docs/ver2.2-test-plan.md)から参照する範囲資料の保存先。

## 最も重要な範囲資料

ユーザーがこのチャットに添付した「東大寺 境内ご案内図」に、赤い長方形と「このエリアを再現してください」を加えた画像。3枚のうち赤枠付きの画像を正本として保持する。無加工の境内図だけでは対象範囲を確定できない。

チャット内の画像内容は確認済みだが、今回この環境へ渡された情報には画像のダウンロードIDやローカルファイルがなく、原本のバイト列を取得できていない。**画像ファイル自体の保存は未完了**。再添付された原本を取得できたら、このフォルダへ元の画質で保存し、ファイル名・ハッシュ・保存日を追記する。公式PDFや描き直した図を原本の代わりに「保存済み」と扱わない。

## 現時点で残す範囲の読み取り

- 南: 大仏前交差点・奈良公園の道路側。
- 中央: 南大門、参道、鏡池、中門・回廊、大仏殿。
- 西: 戒壇院・勧進所方面。
- 東: 国際フォーラム・東塔跡園地・鐘楼側。
- 北: 大仏殿北側付近まで。正確な境界は原本を地図へ対応付けて確定する。

この一覧は画像からの読み取りであり、測量済みの区域ではない。赤枠の原本保存後、四隅と主要ランドマークを実地図へ照合し、区域の緯度経度を記録する。

ユーザー追加指示: 主ルート（交差点〜大仏殿）は重点的にリアルにする。周辺は粗めの造形でよいが、縮尺と位置関係は維持する。
