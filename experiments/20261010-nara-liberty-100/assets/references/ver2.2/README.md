## 現時点で残す範囲の読み取り

- 南: 大仏前交差点・奈良公園の道路側。
- 中央: 南大門、参道、鏡池、中門・回廊、大仏殿。
- 西: 戒壇院・勧進所方面。
- 東: 国際フォーラム・東塔跡園地・鐘楼側。
- 北: 大仏殿北側付近まで。正確な境界は原本を地図へ対応付けて確定する。

この一覧は画像からの読み取りであり、測量済みの区域ではない。次に赤枠の四隅と主要ランドマークを実地図へ照合し、区域の緯度経度を記録する。

ユーザー追加指示: 主ルート（交差点〜大仏殿）は重点的にリアルにする。周辺は粗めの造形でよいが、縮尺と位置関係は維持する。
