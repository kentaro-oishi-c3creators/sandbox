# 初期版の検証記録

2026-10-11（日本時間）。Node24.19、Blender4.3.2、Chromium（Playwright1.56）で確認。

- `npm ci` と `npm run build`：成功。JavaScript約647KB（gzip約170KB）。Viteの500KB超のサイズ注意表示は残る。
- `python tests/geometry.py`：GLBの幅・奥行・高さ、原点中心・底面0、西側入口を通る経路を検証。モデル経路約659.82m（実測の歩行距離ではない）。
- `npm run test:browser`：PC1440×900、モバイル390×844、動きを減らす設定で確認。WebGL2描画、GLB読込、散策・停止、地点移動、スライダー、ドラッグ、キーボード、タッチ前進、俯瞰、品質切替、説明ダイアログ、リセット、横はみ出しなし、停止中の再描画停止を確認。
- ブラウザの寸法：南大門25.459999m、大仏殿57.012001×50.479999×48.742001m。公式寸法との差は浮動小数点の誤差範囲。
- 赤枠の原本は既存の共通assetsに保全。V1・V2のアプリ、公開先は変更していない。

## 未達・未検証

地理データの詳細取得が通信403で制限され、地理的な位置・道路幅・標高・建築細部は推定。テスト計画のS02〜S04の「測量・縮尺付き地図との照合」、V01〜V06の「現地写真比較」は完了していない。モデル内の寸法整合と、現地に一致する精度は別の評価。

S05公式外接寸法、S06Blender→GLB、F01〜F05・F08の基本操作を確認。S07は経路目線を固定し門の基壇に合わせた簡易高度を使用するが、実地段差の精度は未確認。F06の実GPUの30/20FPS目標は、クラウドのソフトウェア描画（SwiftShader）では評価できない。静止中に描画を止める点は検証。

細部・彫刻、店舗の実在外観、路面断面、樹木形状の写実性、実機速度は次の改善対象。現時点はメートル尺度の空間と建築外形を歩いて評価する初期版。
