# 実験 README のひな形

新しい実験の `README.md` にコピーし、その実験に合わせて埋めます。
分からない項目は「未確認」と書き、確認していない手順を動作確認済みにしません。

```markdown
# 実験名

目的：何を試したいか、何ができれば十分か。
状態：作業中 / 保留 / 完了

## 動かし方

- 作業するフォルダ：
- 必要なツールとバージョン：
- 必要な部品を入れるコマンド：
- 起動・実行するコマンド：
- 動作確認の方法と期待する結果：
- 必要な設定の名前：秘密の値は記載しない。
- 停止方法：アプリを起動し続ける場合のみ。

## 結果と次の一手

- 現在できること：
- まだできないこと、既知の制限：
- 次に試したいこと：
```
